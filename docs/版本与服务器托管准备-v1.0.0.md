## 2. 上传到服务器前

1. 本机执行 `npm run pack:release`，得到 zip + `.sha256`
2. 校验：`Get-FileHash releases\dingtalk-reimbursement-1.0.0.zip -Algorithm SHA256`
3. 用 scp/SFTP 传到服务器（勿把含密钥的 `.env` 打进包；包内已排除）
4. 服务器解压到固定目录，例如 `/opt/dingtalk-reimbursement`

---

## 3. 轻量云一键路径（推荐）

```bash
cd /opt/dingtalk-reimbursement
cp .env.production.example .env
# 编辑：MySQL 密码、钉钉四件套、JWT_SECRET、FRONTEND_URL=https://域名/h5

docker compose -f docker-compose.prod.yml up -d --build

docker compose -f docker-compose.prod.yml exec backend \
  sh -c "cd /app && node scripts/init-db.js && node scripts/seed-prod.js"

curl -s http://127.0.0.1:8080/api/health
# 期望含 "version":"1.0.0","db":true
```

前置 HTTPS（Nginx/Caddy）后：

- 钉钉应用首页：`https://你的域名/h5/`
- 安全域名：`你的域名`
- `.env` 中 `FRONTEND_URL` 与首页一致

## 4. 冷启动角色

首位总经理需先登录一次应用，再 SQL：

```sql
INSERT INTO user_role (user_id, role_code, grade, status)
SELECT id, 'gm', 'C', 'active' FROM user_account WHERE ding_user_id = '对方钉钉userid' LIMIT 1;
```

之后在 H5「我的 → 角色分配」点选财务/项目经理；在「项目成员」分配员工可见项目。
