## 需真实钉钉环境才能验证的项

1. **免登登录** — `POST /api/auth/login` + 钉钉 H5 `dd.runtime.permission.requestAuthCode`
2. **JSAPI 鉴权** — `GET /api/auth/js-config`（需正确 AppKey/Secret/CorpId）
3. **方案 B 提交** — 调用钉钉 OA「发起审批实例」API（需有效 `DINGTALK_PROCESS_CODE` 与模板字段对齐）
4. **Stream 长连接** — 生产级 `bpms_instance_change` 推送（需公网或 Stream 可达）
5. **HTTP 加密回调** — `DINGTALK_CALLBACK_TOKEN` + AES Key 验签解密
6. **工作通知 / 待办推送** — 审批节点通知到钉钉客户端
7. **发票 OCR** — 若接入钉钉/第三方 OCR 服务，非文件名启发式解析

本地开发默认 **APPROVAL_MODE=A**（自研 H5 审批），OA 相关 UI 与 webhook 已通过模拟数据验证。
