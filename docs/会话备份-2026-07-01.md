## npm 脚本与运维脚本参考

### backend `package.json`

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发模式启动（`:3000`，watch 热重载） |
| `npm run db:init` | 执行 schema 建表 |
| `npm run db:seed` | 开发 seed（dev_user / dev_manager） |
| `npm run db:seed-prod` | 生产 seed（无 dev 测试账号） |
| `npm run verify:p3` | P3 预算/发票/报表/撤回 验证 |
| `npm run verify:p4` | P4 OA 模拟验证 |
| `npm run verify:p4-http` | P4 HTTP Webhook 验证 |
| `npm run verify:e2e` | P0–P2 冒烟 |
| **`npm run verify:all`** | **全量验证**（e2e + p3 + p4 + p4-http） |

### 根目录 `package.json`

| 命令 | 说明 |
|------|------|
| `npm run dev:backend` | 启动后端 |
| `npm run dev:frontend` | 启动前端 |
| `npm run install:all` | 前后端依赖一键安装 |

### 部署与健康检查

```powershell
# 生产初始化（首次）
.\scripts\deploy\init-production.ps1 -EnvFile backend\.env

# 健康检查
.\scripts\deploy\health-check.ps1 -BackendUrl http://localhost:3000 -FrontendUrl http://localhost:8080
```

### 备份脚本

```powershell
# MySQL 备份（DryRun 预览）
.\scripts\backup\mysql-backup.ps1 -EnvFile backend\.env -DryRun
.\scripts\backup\mysql-backup.ps1 -EnvFile backend\.env

# 附件备份
.\scripts\backup\backup-uploads.ps1

# 恢复（需指定备份文件）
.\scripts\backup\mysql-restore.ps1 -EnvFile backend\.env -BackupFile backups\mysql\xxx.sql.gz
```

备份默认目录：`backups/mysql/`、`backups/uploads/`（已在 `.gitignore`）
