## 一、项目背景与目标

### 1.1 业务场景

面向**园林工程施工企业**的协作报销平台：多工地项目、管理人员、第三方单位及总部多地区/部门统一管理。

| 维度 | 目标 |
|------|------|
| 参考规模 | 内部员工约 150 人，年报销单约 3,000 笔 |
| 年维护成本 | **0.3–0.8 万元**（服务器 + 兼职运维） |
| 平台策略 | **钉钉标准版免费** + 自研 H5 + 自建后端 |
| 明确不用 | 智能财务、宜搭、预算费控、OA 高级版等付费套件 |

### 1.2 技术方案

| 方案 | 说明 | 角色 |
|------|------|------|
| **方案 B（主导）** | H5 填单 → 后端校验 → 钉钉 OA 审批实例 → Stream/Webhook 回写 | 默认生产 |
| **方案 A（降级）** | 全自研审批链 + 钉钉工作通知 | API 超限或不用 OA 时切换 |

**设计原则**：自研 MySQL 库为**唯一业务真相源**；钉钉负责免登、消息、可选 OA UI。

### 1.3 交付阶段总览

| 阶段 | 内容 | 状态 |
|------|------|------|
| P0 | 钉钉自建应用 + 免登 + H5 骨架 | ✅ |
| P1 | MySQL、报销 CRUD、项目选择、附件上传 | ✅ |
| P2 | 自研审批流 + 通知 | ✅ |
| P3 | 预算/发票查重/报表/OCR/用量/撤回 | ✅ |
| P4 | 钉钉 OA 审批 + Stream/Webhook | ✅ |
| P5 | Docker/PM2 部署、备份脚本、管理员手册 | ✅ |
| v1.0.0 | 角色分配、项目成员、自动审批路径、发布包 | ✅ |

### 3.2 报销单

| 功能 | API/页面 |
|------|----------|
| 创建/编辑/列表/详情 | `/api/reimbursements`、`ReimbCreate.vue`、`ReimbList.vue` |

| 撤回 | `POST .../cancel`（审批中申请人） |

### 3.3 审批

| 模式 | 行为 |
|------|------|
| A 自研 | 项目经理 → 财务 →（大额）总经理；提交无需选人 |
| B OA | 钉钉 OA 模板 + Stream/Webhook；需 `DINGTALK_PROCESS_CODE` |
| 待办/候选人/动作/时间线 | `/api/approvals/*` |
| OA 失败 | 保持草稿，`sync_status=failed` |
| 驳回 | 取消其余待办；释放预算占用 |

### 3.4 预算与发票

| 功能 | 说明 |
|------|------|
| 预算占用/释放 | `budget_ledger`；驳回/撤回/OA 终止写 `release` |
| 严格模式 | `budget.strict_mode=true` 超预算拦截 |
| 预算预览 | `GET /api/budget/preview` |
| 发票查重 | `GET /api/invoices/check` |
| 发票 OCR | `POST /api/invoices/ocr`（本地 MVP 正则；待接真实 API） |
| 发票验真 | `invoice.verify_enabled` 默认 false |

| role_code | 档位 | 数据范围 | 说明 |
