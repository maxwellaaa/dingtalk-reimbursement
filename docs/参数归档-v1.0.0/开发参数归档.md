## 5. 数据库 `sys_config`（业务开关）

来源：`database/schema.sql`

| config_key | 默认 | 含义 |
|------------|------|------|
| `approval.mode` | `B`（seed 开发常改 `A`） | A=自研 H5；B=钉钉 OA |
| `dingtalk.process_code` | 空 | OA 模板编码 |
| `budget.strict_mode` | `true` | 超预算拦截 |
| `invoice.duplicate_check` | `true` | 发票查重 |
| `invoice.verify_enabled` | `false` | 第三方验真 |
| `api.usage.warn_threshold` | `8000` | API 用量预警 |
| `approval.finance_a_max` | `5000` | 财务 A 档上限（元） |
| `approval.finance_b_max` | `50000` | 财务 B 档上限 |
| `approval.gm_a_max` | `50000` | 总经理 A 档上限 |
| `approval.gm_b_max` | `200000` | 总经理 B 档上限 |

代码内常量（`accessScope.js`）与上表金额阈值对齐：

- `financeAMax=5000`，`financeBMax=50000`，`gmAMax=50000`，`gmBMax=200000`
- 报销 ≤5000 可跳过总经理节点（自研审批路径）

## 6. 角色与权限参数

| role_code | 档位 | 范围 | 说明 |
|-----------|------|------|------|
| `employee` | — | 本人单据 | 入企默认；不可自助入项目 |
| `project_manager` | A/B/C | 绑定 `project_id` | 本项目审批第一环 |
| `finance` | A 项目 / B 片区 / C 公司 | 见分配 | 第二环；C 可角色管理（不可管 GM） |
| `gm` | A/B/C | 全公司 | 大额；**仅 GM 可分配 GM** |

**冷启动首位总经理**（对方先登录一次）：

```sql
INSERT INTO user_role (user_id, role_code, grade, status)
SELECT id, 'gm', 'C', 'active' FROM user_account WHERE ding_user_id = '对方userid' LIMIT 1;
```

**项目成员**：由财务 C / 总经理 / 项目经理在「项目成员」分配后，员工填单才可见该项目。

## 8. 审批路径（业务参数摘要）

| 模式 | 行为 |
|------|------|
| A 自研 | 本项目经理 → 本项目财务 →（大额）总经理；提交无需选人 |
| B OA | 钉钉 OA 模板 + Stream/Webhook 回写；需 `processCode` |

附件控件 label 默认：`发票及凭证`（可用 `DINGTALK_OA_ATTACHMENT_LABEL` 覆盖）。
