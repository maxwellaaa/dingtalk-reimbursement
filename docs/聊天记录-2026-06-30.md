### 3. 极低成本自研方案

**用户**：能否基于钉钉开发企业自用协作报销平台，年维护费用极低，尽量少用或不用钉钉收费功能？

**助手**：**完全可行**。

- **设计原则**：钉钉当「门」（登录、消息、可选 OA 审批），不当「引擎」；业务、数据、审批逻辑全部自研。
- **明确不用**：智能财务、宜搭、预算费控、OA 高级版、专业版（除非 API 超限）。
- **两种审批模式**：
  - **方案 A**：全自研审批，钉钉只发工作通知（API 用量最少）
  - **方案 B**：H5 填单 → 免费 OA 审批实例 → Stream 事件回写（体验更接近原生）
- **年费用**：约 **0.26–0.65 万/年**（服务器 + 兼职运维）；对比付费套件 5–16 万/年。
- **API 控费**：事件驱动、通讯录每日同步、Token 缓存；150 人/3000 单约 800–2000 次/月，低于标准版 1 万次上限。
