## 明日启动步骤（PowerShell）

### 1. 确认 MySQL 在运行

```powershell
Get-Service -Name "MySQL*" | Select-Object Name, Status
```

若未运行，可在「服务」中启动 **MySQL97**，或：

```powershell
Start-Service MySQL97
```

快速连通性检查（使用项目账号，**不要用 root 密码写进文档**）：

```powershell
& "C:\Program Files\MySQL\MySQL Server 9.7\bin\mysql.exe" -u reimb -preimb123 -e "SELECT 1 AS ok;"
```

### 2. 启动后端（终端 1）

```powershell
cd "f:\obsidian知识库\cursor\dingtalk-reimbursement\backend"
npm run dev
```

期望日志：`[backend] P0 running at http://localhost:3000`（或同类启动成功提示）。

> 若 P3 代码有更新，需**重启**此终端（`node --watch` 多数情况会自动重载，不确定时 Ctrl+C 后重新 `npm run dev`）。

### 3. 启动前端（终端 2）

```powershell
cd "f:\obsidian知识库\cursor\dingtalk-reimbursement\frontend"
npm run dev
```

期望：`Local: http://localhost:5173/h5/`  
浏览器打开：**http://localhost:5173/h5/**

> 只跑 `npm run build` **不会**占用 5173；开发必须用 `npm run dev`。

### 4. 健康检查

```powershell
curl http://localhost:3000/api/health
```

期望：`"db": true`，`"phase": "P3"`（或更高）。

### 5. P3 自动化验证（可选，推荐先跑）

```powershell
cd "f:\obsidian知识库\cursor\dingtalk-reimbursement\backend"
node scripts/verify-p3.js
```

期望：一系列 `[ok]` 日志，末尾 `[ok] cleanup done`。

## 开发测试流程

1. 浏览器打开 **http://localhost:5173/h5/**（非钉钉环境自动 dev-login）
2. 默认身份：**开发测试员**（`dev_user`）→ 新建报销 → 填项目/科目/金额/发票号 → 提交
3. 「我的」页切换为 **项目经理 dev_manager** → 「待办」Tab → 审批通过
4. 再切回 **dev_user**（若流程含财务节点）→ 待办中财务审批通过
5. 首页「项目预算」→ 进入 **项目看板**，核对总预算 / 已用 / 科目明细
6. 重复提交相同发票号，应被查重拦截

## 已知问题与注意事项

| 问题 | 处理 |
|------|------|
| Docker / WSL 不可用 | **改用本机 MySQL 9.7**，不影响日常开发 |
| 前端 `ERR_CONNECTION_REFUSED` | 确认终端 2 已 `npm run dev` |
| 后端接口旧行为 | 重启 backend 终端，确保加载最新 P3 代码 |
| 钉钉内免登 | 需开放平台配置 + 内网穿透；本地先用 dev-login |
| seed 数据缺失 | `npm run db:seed`（verify-p3 会报 seed data missing） |
