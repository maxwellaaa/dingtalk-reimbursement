## 7. 认证与权限

### 7.1 登录方式

| 方式 | 端点 | 说明 |
|------|------|------|
| 钉钉 H5 免登 | `POST /api/auth/login` | body: `{ authCode }` |
| JSAPI 配置 | `GET /api/auth/js-config` | `dd.config` |
| 当前用户 | `GET /api/auth/me` | Bearer JWT |
| 身份确认 | `POST /api/auth/confirm-identity` | 写审计日志 |
| 开发登录 | `POST /api/auth/dev-login` | **仅非 production** |
| 公开配置 | `GET /api/auth/config` | corpId、agentId 等 |

### 7.2 JWT

| 参数 | 值 |
|------|-----|
| Header | `Authorization: Bearer <token>` |
| 载荷 | `sub`（user id）、`role`、`phone` |
| 有效期 | `JWT_EXPIRES_IN`，默认 `7d` |

### 7.3 角色（`user_role`）

| role_code | 档位 | 数据范围 |
|-----------|------|----------|
| `employee` | — | 本人单据 |
| `project_manager` | A/B/C | 绑定 `project_id` |
| `finance` | A/B/C | 项目/片区/公司 |
| `gm` | A/B/C | 全公司 |

**金额阈值**（`accessScope.js`）：financeA 5000、financeB 50000、gmA 50000、gmB 200000；报销 ≤5000 可跳过总经理节点。

### 7.4 开发种子账号（`npm run db:seed`）

| ding_user_id | 姓名 | 用途 |
|--------------|------|------|
| `dev_user` / `dev_user_2` | 开发测试员 | 员工 |
| `dev_manager` / `dev_pm_b` / `dev_pm_c` | 项目经理 | 项目 001/002/003 |
| `dev_finance_a/b/c` | 财务 | |
| `dev_gm_a/b/c` | 总经理 | |

**dev-login role 参数**：`employee` / `pm:A|B|C` / `finance:A|B|C` / `gm:A|B|C`

**示例项目编码**：`HD-2026-001` / `002` / `003`；片区 `HD-GZ`

## 10. 审批模式

| 模式 | 行为 |
|------|------|
| **A 自研** | 项目经理 → 财务 →（大额）总经理；提交无需选人 |

## 12. 常用命令

```powershell
# 安装
npm run install:all

# 数据库
cd backend
npm run db:init
npm run db:seed          # 开发种子
npm run db:seed-prod     # 生产种子（无 dev 用户）

# 开发
npm run dev:backend      # 3000
npm run dev:frontend     # 5173

# 验证（全套）
npm run verify:all

# 手机真机穿透
npm run mobile:start
npm run mobile:stop

# 发布包
npm run pack:release
```
